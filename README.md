# 국민핏맵 (Gukmin FitMap)

2026년 국민체육진흥공단(KSPO) 공공데이터 활용 경진대회 — 서비스개발 부문 출품작

**서비스 URL**: https://gukmin-fitmap-kr.netlify.app/

## 소개

국민체력100 체력측정 데이터는 전국 229개 시군구 중 71곳(약 31%)에만 측정센터가 있어, 나머지 158개 지역 주민은 공공 체력측정 서비스에 물리적으로 접근하기 어렵습니다.

국민핏맵은 이 문제를 "개인 체력 진단 → 지역 단위 집계 → 지자체 정책 제안"으로 이어지는 하나의 데이터 파이프라인으로 연결합니다. 개인이 자신의 체력을 진단받는 행위 자체가 익명화된 상태로 지역 정책 데이터를 두텁게 만드는 구조입니다.

## 주요 기능

- **개인 진단**: 지역·연령대·성별 기준 BMI·악력 비교 진단, 추천 운동 처방
- **시설 찾기**: 거리 기반 공공·민간 체육시설 추천 (카카오맵 연동)
- **정책 대시보드**: 시군구 단위 체력취약지수 × 시설부족지수 기반 정책우선순위지수, 시설추가 시뮬레이션(What-if)

## 활용 데이터

국민체육진흥공단(KSPO) 및 체육종합빅데이터센터 제공 공공데이터 6종을 활용했습니다 (국민체력측정 결과, 전국체육시설 정보, 지역별 공공체육시설 보급현황, 스포츠강좌이용권 활용 정보 등). 자세한 데이터 출처·수집 시점은 제출 보고서([붙임1] 0장, 4.1절) 참고.

## 기술 스택

단일 HTML 파일(index.html) 기반 웹서비스 — D3.js(시군구 코로플레스 지도), 카카오맵 JS SDK(위치 기반 시설 추천), Netlify(배포).
